# Юнит-тестирование приложения Stellar Burgers

Первая часть дипломного проекта по тестированию ПО в Яндекс Практикуме.

## Цель
Проверить методы класса `Burger` с помощью модульных тестов и оценить покрытие кода.

## Выполненные задачи
- Проверка установки булочки, добавления, удаления и перемещения ингредиентов.
- Проверка расчёта стоимости бургера.
- Проверка формирования чека на двух наборах данных (параметризованный тест).
- Использование мок-объектов Mockito для изоляции зависимостей.
- Формирование отчёта JaCoCo.

## Инструменты
Java 11, JUnit 4.13.2, Mockito 5.23.0, Maven, JaCoCo 0.8.14, Git, GitHub.

## Результаты
Разработано пять обычных юнит-тестов и один параметризованный тест с двумя наборами данных (семь запусков). По сохранённому отчёту JaCoCo достигнуто 100% покрытия класса `Burger` по инструкциям, ветвлениям, строкам и методам. Дипломная работа принята.

## Структура проекта
- [`src/test/java/praktikum/`](src/test/java/praktikum/) — самостоятельно разработанные тесты.
- [`pom.xml`](pom.xml) — конфигурация Maven и зависимости.
- [`jacoco-report/jacoco.csv`](jacoco-report/jacoco.csv) — сохранённые результаты покрытия.
- `.gitignore` — исключения для Git.

## Запуск тестов
Исходный код приложения предоставлен Яндекс Практикумом и не включён в эту копию портфолио. Для запуска необходимо восстановить оригинальную папку `src/main/java/praktikum/` из учебного проекта, установить JDK 11 или совместимую более новую версию и Maven, затем выполнить `mvn clean verify` из папки проекта. Отчёт JaCoCo будет сформирован в `target/site/jacoco/`.

Сохранённый CSV относится к исходной дипломной работе; после подготовки копии повторный запуск не выполнялся.
