# UI-тестирование Stellar Burgers

Третья часть дипломного проекта Яндекс Практикума — автоматизация UI-тестирования веб-приложения Stellar Burgers.

## Инструменты
Java 11, Maven, JUnit 4, Selenium WebDriver, REST Assured, Allure, Page Object.

## Проверки
- Регистрация: успешная регистрация и ошибка при коротком пароле (2 теста).
- Авторизация: вход с главной страницы, через форму регистрации и форму восстановления пароля (3 теста).
- Конструктор: переключение вкладок «Булки», «Соусы», «Начинки» (3 теста).

## Результаты
В сохранённом отчёте Яндекс Браузера: 8 тестов, 8 успешно, 0 ошибок. В коде предусмотрен выбор Chrome или Яндекс Браузера; результаты Chrome не представлены.

- `src/main/java/pageobject` — объекты страниц.
- `src/test/java` — тесты, API-клиент, модели и конфигурация.
