# Автоматизация API-тестирования приложения Stellar Burgers

Вторая часть дипломного проекта по тестированию ПО в Яндекс Практикуме.

## Цель
Проверить REST API приложения с помощью автоматизированных позитивных и негативных тестов.

## Выполненные задачи
- Проверка создания уникального и уже существующего пользователя, отсутствия обязательных полей email, password и name.
- Проверка авторизации с корректными и некорректными данными.
- Проверка создания заказа с авторизацией и без неё, без ингредиентов и с некорректным идентификатором ингредиента.
- Проверка HTTP-статусов и содержимого ответов API.
- Создание API-клиентов, моделей данных и генератора тестовых пользователей.
- Формирование отчёта Allure.

## Инструменты
Java 11, JUnit 4.13.2, REST Assured 5.5.1, Maven, Allure, Jackson, Lombok, Git, GitHub.

## Результаты
Разработано 12 автотестов: 5 на создание пользователя, 3 на авторизацию и 4 на создание заказа. По сохранённому отчёту Allure от 02.08.2026 все 12 тестов пройдены успешно.

## Структура проекта
- [`src/test/java/praktikum/tests/`](src/test/java/praktikum/tests/) — автотесты.
- [`src/main/java/praktikum/`](src/main/java/praktikum/) — API-клиенты, модели, конфигурация и генератор тестовых данных.
- [`pom.xml`](pom.xml) — конфигурация Maven и зависимости.
- [`allure-report/suites.csv`](allure-report/suites.csv) — результаты тестов.
- [`allure-report/summary.json`](allure-report/summary.json) — сводка результатов.

## Запуск тестов
Необходимы JDK 11, Maven и доступ к учебному API Stellar Burgers. Из папки проекта выполнить:

```bash
mvn clean test
mvn allure:serve
```

Сохранённые результаты относятся к исходной дипломной работе. После подготовки копии портфолио повторный запуск не выполнялся. Доступность учебного стенда не проверялась.
